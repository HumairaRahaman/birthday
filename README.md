# Jhon — The Boss Is Coming

A mobile-friendly birthday surprise website for Jhon.

## Features
- Date-of-birth entry screen (9 November)
- Funny access-denied screen for an incorrect date
- Birthday stadium animation followed by the Nando's surprise animation
- Original browser-generated background music with an on/off control
- Final thank-you screen

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it so the animations load correctly.

## Deploy
This is a static website. Deploy the repository with GitHub Pages, Netlify, or Vercel. No build command is required.

The date check is a playful client-side gate, not secure authentication.
